Privacy Policy - GitHub Pull Request Ultimate

Last updated: 2026-06-01

GitHub Pull Request Ultimate is a Chrome extension that gives you a personal dashboard for the GitHub pull requests across the repositories you follow. This page explains exactly what data the extension touches, what it does with it, and what it does not do.

What we collect

Nothing. The extension does not collect, transmit, sell, or share any personal information, browsing history, analytics, telemetry, or usage data. There are no accounts, no logins, and no remote servers operated by us. The only service it ever contacts is GitHub's own API, using the access token you provide.

What the extension reads

Using the GitHub personal access token you provide, and only for the repositories you add, the extension reads:

  • Your pull requests and their details Γאפ title, author, branches, status, checks, approvals, reviewers, labels, files and diffs.
  • Review comments and threads on those pull requests, so you can read and reply to them.
  • Your GitHub notifications feed (only if you enable desktop alerts).

This is requested directly from GitHub over HTTPS and used only to show your dashboard and carry out the actions you take. It is never sent anywhere other than GitHub.

What the extension stores

Your access token, settings, subscribed repositories, priority flags, and a local cache of the pull-request data above are stored using chrome.storage.local. This is Chrome's built-in extension storage, kept on this browser only Γאפ it is not synced to your other devices, and we do not have access to it.

Permissions, and why we need them

  • storage Γאפ save your token, settings, subscribed repositories, and the PR cache.
  • alarms Γאפ refresh your PRs in the background on your chosen schedule, and poll for notifications.
  • notifications Γאפ only used if you turn on desktop alerts about review activity.
  • host access to https://api.github.com Γאפ read your PRs and perform the actions you choose (approve, comment, request reviewers, resolve threads, edit a file, toggle auto-merge, etc.).

The extension does not request the tabs permission, requests no host access to any site other than GitHub's API, and never injects scripts into web pages.

Third parties

The extension communicates only with GitHub (api.github.com), using your token, to do what you ask; GitHub's own privacy policy applies to your use of GitHub. The only other outbound link is an optional PayPal donate button in Settings, which opens PayPal in a new tab if (and only if) you click it. There are no analytics, trackers, or other third parties.

Children

The extension is a developer tool, is not directed at children, and does not knowingly process any data from children.

Changes to this policy

If this policy changes, the updated version will be posted at the same URL with a new "Last updated" date.

Contact

Questions or concerns: open an issue on the extension's repository, or contact the publisher email associated with the Chrome Web Store listing.
